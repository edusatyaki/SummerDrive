## 📌 Project Overview

The **NYC Taxi Dashboard** is an interactive Tableau project built using the **NYC Yellow Taxi Trip Records** dataset. It provides a comprehensive analysis of taxi operations and revenue performance through intuitive visualizations and KPI-driven dashboards.

---

## 📊 Dashboards Included

### 1. Operations Overview

Provides a high-level overview of taxi demand and operational performance.

**KPIs**
- Total Trips
- Total Revenue
- Average Fare
- Average Trip Duration

**Visualizations**
- Hourly Trip Volume
- Revenue by Pickup Hour
- Payment Method Distribution
- Trip Distance Distribution

---

### 2. Revenue Performance

Focuses on revenue generation and customer payment behaviour.

**KPIs**
- Average Tip Percentage
- Revenue per Mile
- Average Passenger Count
- Average Trip Distance

**Visualizations**
- Trip Distance vs Total Amount
- Average Tip Percentage by Payment Method
- Fare Components Breakdown
- Revenue by Vendor
