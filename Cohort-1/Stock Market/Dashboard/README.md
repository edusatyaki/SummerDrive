# Purpose

Design and develop an interactive Tableau dashboard that presents stock market insights in a clear and business-friendly manner. The dashboard enables users to analyze historical stock performance, forecast accuracy, trading behavior, and investment growth through interactive visualizations and KPIs.

---

# Dashboard Objectives

- Present stock market performance using interactive visualizations.
- Enable users to compare multiple business metrics.
- Provide an easy-to-understand overview of stock performance.
- Evaluate prediction accuracy using forecasting metrics.
- Support data-driven investment analysis.

---

# Dashboard Features

- Interactive Stock Selector
- KPI Cards
  - Total Return (%)
  - Latest Price
  - Average Volume
- Historical Price Trend
- Cumulative Growth Analysis
- Daily Returns Distribution
- Volatility Analysis
- Best Trading Days
- Worst Trading Days
- Forecast Accuracy
  - RMSE
  - MAPE

---

# Business Insights Used

The dashboard is built using insights generated during the **Data Analysis** phase, including:

- Historical price movement of stocks
- Overall return generated by each stock
- Trading volume comparison
- Market volatility analysis
- Daily return distribution
- Best and worst performing trading days
- Prediction accuracy using RMSE and MAPE
- Growth of an initial investment over time

---

# Dashboard Usage

1. Open the Tableau Workbook (`Stock Market Dashboard.twbx`).
2. Select a stock using the **Ticker Filter**.
3. Review the KPI cards for a quick summary.
4. Explore charts to analyze trends, volatility, returns, and prediction accuracy.
5. Use different dashboard pages for detailed analysis.
