**Cohort:** Cohort-2  
**Owner:** Kanchan Rani

---

## Project Overview

This project analyzes an A/B Testing dataset to compare the performance of the **Ad** and **PSA** groups. The analysis includes descriptive statistics, hypothesis testing, and exploratory data analysis (EDA) to identify user behavior, conversion patterns, and business insights.

> **Note:** This project uses the cleaned dataset generated in the **Data Cleaning** phase. The dataset is not included again in this folder.

---

## Objectives

- Compare conversion rates between the Ad and PSA groups.
- Perform statistical tests to validate the results.
- Explore data using visualizations.
- Generate business insights and recommendations.
- Prepare findings for dashboard development and reporting.

---

## Analysis Performed

### Statistical Analysis
- Descriptive Statistics
- Conversion Rate Analysis
- Chi-Square Test
- 95% Confidence Interval
- Cohen's h (Effect Size)
- Mann–Whitney U Test
- Spearman Correlation
- Chi-Square Test (Most Ads Day)
- Chi-Square Test (Hour Group)

### Exploratory Data Analysis
- Test Group Distribution
- Conversion Distribution
- Total Ads Distribution
- Conversion Rate by Test Group
- Total Ads by Test Group
- Most Ads Day Analysis
- Conversion Rate by Day
- Most Ads Hour Analysis
- Conversion Rate by Hour Group
- Correlation Heatmap
- Pairplot
- Conversion by Test Group
- Total Ads vs Conversion
