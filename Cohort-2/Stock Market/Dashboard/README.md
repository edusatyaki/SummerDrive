# Purpose

This folder contains the Tableau dashboards developed for the Stock Market Analysis project. The dashboards transform the cleaned stock market dataset into interactive visualizations that help analyze stock performance, trading activity, price trends, volatility, and investment insights.

The dashboards are designed to present meaningful business insights for investors and decision-makers through KPIs, charts, and interactive filters.

---

# Dashboard Overview

## Dashboard 1 – Executive Overview
Provides a high-level summary of stock market performance.

### KPIs
- Total Trading Days
- Stocks Analyzed
- Average Closing Price
- Highest Closing Price
- Lowest Closing Price
- Average Daily Trading Volume

### Visualizations
- Yearly Average Daily Price Range
- Average Closing Price by Stock
- Yearly Closing Price Trend
- Average Trading Volume by Stock

### Filters
- Select Stock
- Select Year

---

### Visualizations
- Closing Price Distribution

# Key Business Insights

The dashboards help answer the following business questions:

- Which stock has the highest average closing price?
- Which stock experiences the highest trading activity?
- How have stock prices changed over time?
- Which periods experienced the highest price volatility?
- How does trading volume relate to stock prices?
- Which stock delivers better returns with lower risk?
- Which stock performs consistently across different months?

# Usage

1. Open the Tableau Workbook (.twbx).
2. Use the dashboard navigation buttons to switch between dashboards.
3. Apply the filters (Stock, Year, Month) to interact with the visualizations.
4. Hover over charts to view detailed tooltips and insights.
