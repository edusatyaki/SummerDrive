# 📊 Dashboards Included

## 1️⃣ NYC Taxi Performance Dashboard

Provides a high-level overview of taxi operations.

### KPIs
- Total Trips
- Total Revenue
- Average Fare
- Average Passengers
- Average Tip
- Average Trip Distance

### Visualizations
- Monthly Revenue Trend
- Top Pickup Locations
- Revenue by Payment Type
- Average Tip by Passenger Count
- Average Fare by Pickup Hour

---

## 2️⃣ NYC Taxi Revenue Analysis Dashboard

Analyzes revenue generation patterns.

### KPIs
- Average Revenue per Trip
- Credit Card Revenue %
- Cash Revenue %
- Total Tips Collected
- Average Tip per Trip
- Highest Revenue Pickup Location

### Visualizations
- Weekly Revenue Distribution
- Revenue by Fare Type
- Revenue by Hour & Day of Week
- Average Fare vs Trip Distance
- Revenue by Trip Distance

---

## 3️⃣ NYC Taxi Customer & Trip Behaviour Dashboard

Focuses on customer travel behavior and trip characteristics.

### KPIs
- Average Trip Duration
- Average Speed
- Average Fare per Mile
- Average Fare per Minute

### Visualizations
- Passenger Count Distribution
- Average Trip Duration by Pickup Hour
- Fare Amount vs Trip Distance
- Average Taxi Speed by Pickup Hour
- Average Fare per Mile by Trip Type

---

## 4️⃣ NYC Taxi Operational Performance Dashboard

Provides operational charge analysis.

### KPIs
- Average Congestion Surcharge
- Average Airport Fee
- Average Extra Charges
- Average Improvement Surcharge

### Visualizations
- Average Extra Charges by Rate Code
- Average Congestion Surcharge by Pickup Hour
- Average Toll Charges by Trip Type
- Average Total Amount by Pickup Hour
- Average Airport Fee by Rate Code
